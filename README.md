# 🌱 AGRINOVA — AI-Enabled Pest Detection Appilication 

### AI-Powered Smart Agriculture & Crop Monitoring System

Agrinova is an AI-powered smart agriculture solution that combines **drone-based image acquisition, deep learning, and Android application technology** to support automated crop monitoring and pest detection.

The system is designed to help identify pest-affected areas from crop images and present AI-based detection results through a user-friendly Android application.

---

## 🚀 Project Overview

Agricultural fields require continuous monitoring to identify pest infestations at an early stage. Traditional manual inspection can be time-consuming, labour-intensive, and difficult to scale across large farming areas.

**Agrinova** addresses this challenge by combining drone-based image capture, AI-powered image analysis, and a mobile application.

### Core Workflow

**🚁 Drone → 📷 Image Capture → 🧠 AI Detection → 📡 Data/API → 📱 Android Application**

The system is designed for crop monitoring and pest detection across:

- 🍇 Grapes
- 🌾 Sugarcane
- 🍅 Tomato

---

## 🎯 Problem Statement

Early identification of pest infestation is important for maintaining crop health and reducing potential agricultural losses.

Traditional monitoring methods may involve:

- Manual field inspection
- Large amounts of time and labour
- Difficulty monitoring large agricultural areas
- Delayed identification of pest-affected regions
- Dependence on continuous human observation

Agrinova aims to improve this process using **automated aerial image analysis and AI-based pest detection**.
